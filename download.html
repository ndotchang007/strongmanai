Install Strongman AI

Add Strongman AI to your home screen. Official builds from this site only — no APK, no sideloading, no third-party mirrors.

iOS

Safari required

iPhone & iPad

Open this page in Safari, then add Strongman AI to your home screen.

  1. Tap the Share button in Safari's toolbar (square with an arrow).
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add in the top right corner.
  4. Open Strongman AI from your home screen and sign in.

In-app browsers (Instagram, TikTok, etc.) cannot install apps. Copy the link and open it in Safari if needed.

Android

Chrome

Android phones & tablets

Open this page in Chrome, then install the app to your home screen.

  1. Tap Install app below — Chrome will show a confirmation.
  2. Or tap the menu (⋮) → Install app or Add to Home screen.
  3. Confirm the install, then open Strongman AI from your home screen.

Desktop Chrome and Edge can install the same way using the install icon in the address bar.
